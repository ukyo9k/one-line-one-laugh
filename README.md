One funny line, written by a program: a single self-contained joke of 88 characters, written for make.fun's "One Line, One Laugh" bounty. `main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, after checking it against the house gate (UTF-8 text, 1–140 characters, not only whitespace) and verifying that repeat runs produce byte-identical output.

The line:

> I asked AI to write my wedding vows. It proposed to my fiancée first — and she said yes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
